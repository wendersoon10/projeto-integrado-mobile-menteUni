\# MenteUni



\## Sobre o projeto



O MenteUni é um aplicativo mobile voltado à saúde mental de estudantes universitários. A proposta é oferecer recursos que auxiliem os estudantes a acompanhar seu bem-estar emocional, reconhecer situações de estresse e ansiedade relacionadas à rotina acadêmica e desenvolver hábitos de autocuidado.



O projeto busca incentivar a conscientização sobre saúde mental no ambiente universitário e facilitar o acesso a informações e recursos de apoio.



\## Objetivos



\- Incentivar o cuidado com a saúde mental durante a vida acadêmica.

\- Permitir o registro e o acompanhamento do bem-estar emocional.

\- Disponibilizar informações e recursos relacionados ao autocuidado.

\- Contribuir para a conscientização sobre estresse e ansiedade no contexto universitário.

\## Tecnologias e ferramentas



\### Aplicativo mobile



\- \*\*Ionic:\*\* componentes para construção da interface mobile.

\- \*\*Angular:\*\* framework utilizado no desenvolvimento do front-end.

\- \*\*TypeScript:\*\* linguagem utilizada na aplicação.

\- \*\*Chart.js:\*\* biblioteca prevista para a apresentação de gráficos.



\### Back-end



\- \*\*Java 21:\*\* linguagem de programação.

\- \*\*Spring Boot:\*\* framework para desenvolvimento dos serviços do back-end.

\- \*\*Spring Security:\*\* gerenciamento de autenticação e autorização.

\- \*\*JWT:\*\* autenticação baseada em tokens.

\- \*\*Spring Data JPA:\*\* acesso e persistência dos dados.

\- \*\*Flyway:\*\* gerenciamento das migrações do banco de dados.

\- \*\*OpenAPI/Swagger:\*\* documentação da API.

\- \*\*Docker:\*\* suporte à execução dos serviços em containers.



\### Banco de dados



\- \*\*MySQL 8.0:\*\* banco de dados relacional para armazenamento das informações da aplicação.



\### Versionamento e colaboração



\- \*\*Git:\*\* controle de versão do código-fonte.

\- \*\*GitHub:\*\* hospedagem do repositório e colaboração entre os integrantes da equipe.

\- `app/`: código-fonte do aplicativo mobile.

\- `tests/`: arquivos e recursos destinados aos testes.



\## Como executar o projeto



O projeto encontra-se na etapa inicial de organização e configuração do repositório. As instruções detalhadas de instalação e execução serão incluídas conforme os componentes da aplicação forem implementados.



As ferramentas previstas para o ambiente de desenvolvimento incluem Node.js e npm para o front-end, Java 21 e Maven para o back-end, além do MySQL para persistência dos dados.



\## Fluxo de desenvolvimento



O projeto utiliza um fluxo de trabalho baseado no Git Flow simplificado:



\- `main`: branch destinada às versões estáveis do projeto.

\- `develop`: branch de integração das alterações da equipe.

\- `feature/`: branches utilizadas no desenvolvimento de funcionalidades.

\- `docs/`: branches destinadas a alterações na documentação.



As alterações devem ser submetidas por meio de Pull Requests, respeitando as regras de revisão e aprovação definidas no repositório.
