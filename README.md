# projeto-integrado-mobile-menteUni
O MenteUni é um aplicativo mobile voltado à saúde mental de estudantes universitários. Seu objetivo é oferecer recursos e informações que auxiliem no enfrentamento do estresse e da ansiedade acadêmica, promovendo o bem-estar emocional, o autocuidado e o acesso ao apoio psicológico.
